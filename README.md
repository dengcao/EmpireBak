# 帝国备份王(EmpireBak)：稳定、高效、兼容的MYSQL数据库备份系统

## 最新版本：6.0

## 帝国备份王(EmpireBak)简介

帝国备份王(EmpireBak)是一款完全开源免费、专门为MYSQL大数据的备份与导入而设计的稳定高效软件，系统采用分卷备份与导入，理论上可备份任何大小的数据库。

### 帝国备份王解决MYSQL备份三大难题：

1. 解决备份大数据问题，采用分组备份，备份稳定高效；
2. 解决备份数据编码乱码问题，备份王智能识别编码；
3. 解决不同MYSQL版本数据不能互导问题，通过备份王不存在数据版本区别。

## EBMA系统：更安全的MYSQL数据库管理和备份系统

(EmpireBak+phpMyAdmin+高安全)

### EBMA系统简介

“EmpireBak+phpMyAdmin+高安全”整合包就是EBMA系统、开源免费。是一款更安全的MYSQL数据库管理和备份系统。字母取自“Empire”的E、“Bak”的B、“My”的M、“Admin”的A。

### EBMA系统优势

1. 高安全性；
2. 帝国备份王备份大数据稳定高效；
3. 高安全的phpMyAdmin，管理更放心；
4. 支持多MYSQL服务器一起管理与备份；
5. 不同MYSQL版本平滑转换，系统自动识别，兼容性好；
6. 自带探针功能，方便检测服务器运行环境状态；
7. 可以按需开启phpMyAdmin，使用时开启，不使用时关闭，后台直接在线设置；
8. 安装使用方便：全部WEB在线配置参数，无需手动修改文件；
9. 管理和备份MYSQL用一套EBMA系统就够了，不用重复安装设置，安全又方便。

## 本次主要升级功能列表

1. 新增支持 `PHP8.*` 运行环境。（PHP4.2及以上环境都可以安装）

2. 登录认证新增文件验证（并且可设置是否验证文件过期时间），安全性更强。

3. 支持选择兼容INNODB引擎，兼容性更好。

4. EBMA新增多个版本的phpmyadmin，基本覆盖各种运行环境。

5. 兼容帝国CMS8.0版备份格式：即备份的数据可复制到帝国CMS8.0版里恢复。

6. 支持关闭使用模块，可自行关闭不使用的模块。（在配置文件里设置）

7. 新增“登录地址验证参数”功能：设置后登录地址必须加该参数变量名和参数内容才可以登录后台，即使被知道后台目录名，没有参数一样登录不了，在可自定义后台目录名基础上又加了一把锁，更安全。具体使用方法如下：
   1. 后台 > 全局参数设置 > 管理员设置：设置“登录地址验证参数变量名”和“登录地址验证参数”。比如设置为：参数变量名设置为“id”、参数为“empirecms,cs”；
   2. 设置后登录地址要用 `index.php?id=empirecms,cs`，不然登录不了。

8. 上传目录单独。

9. 默认关闭错误提示。

10. 初始化变量更全面。

11. count函数修改支持PHP8。

12. 新增是否严格控制开关。

13. 随机字符数采用随机长度。

14. PHP7以上环境自动识别使用mysqli接口，更自动化。

15. 新增时区设置。（在配置文件里设置）

16. 默认语言改为简体utf8。

17. 对https的识别再次优化，兼容性更好。

18. 支持IPV6。

19. 后台首页界面修改。

20. 随机字符优化。

21. 登录文件支持自定义。具体使用方法如下：
    1. 重命名登录表单文件 `index.php` 和登录处理文件 `ebakdologin.php`；
    2. 修改登录表单文件 `index.php` 里的 `$ebakdologinfile='ebakdologin.php';`，把文件名改为重命名后的登录处理文件名即可。

22. 支持自定义保存设置目录。（全局参数设置）

23. 新增识别更多引擎。

24. 默认数据库链接地址改为 `127.0.0.1`，兼容更多运行环境。

25. 每次登录采用独立登录验证文件。

26. 默认关闭执行SQL和替换文件模块。（可在配置文件里开启）
